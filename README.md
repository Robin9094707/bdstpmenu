# Teleport Menu Behavior Pack

Dieses Projekt stellt ein modernes Minecraft: Bedrock Behavior Pack bereit, das ein komfortables Teleport-Menü ganz ohne Ressourcenpaket anbietet. Spieler öffnen das Menü mit einem ganz normalen Stock und können darüber Teleport-Anfragen an andere Spieler senden sowie eingehende Anfragen annehmen oder ablehnen.

## Funktionen

- Öffne das Menü durch Interaktion mit einem gewöhnlichen Stock (`minecraft:stick`).
- Sende Teleport-Anfragen an andere Online-Spieler mit nur wenigen Klicks.
- Verwalte eingehende Anfragen in einem übersichtlichen Menü mit Annahme- und Ablehnoptionen.
- Automatische Bereinigung, wenn Spieler die Welt verlassen, sodass keine veralteten Anfragen übrig bleiben.
- Begrüßungsnachricht für neu joinende Spieler mit Hinweis auf das Teleport-Menü.
- Komplette Umsetzung nur als Behavior Pack – es wird kein Ressourcenpaket benötigt.

## Installation

1. Kopiere den Ordner `behavior_packs/TeleportMenuBP` in den `behavior_packs`-Ordner deiner `com.mojang`-Verzeichnisstruktur.
2. Aktiviere das Behavior Pack in deiner Welt und schalte die **Beta-API (Scripting)** im Welt-Experimente-Menü frei.
3. Starte die Welt. Beim ersten Spawn erhalten Spieler einen Hinweis, dass sie einen Stock benutzen können, um das Teleport-Menü zu öffnen.

## Nutzung

- Öffne das Inventar und nimm einen normalen Stock in die Hand.
- Interagiere (Rechtsklick/Tippen) mit dem Stock, um das Hauptmenü zu öffnen.
- Wähle "Teleport-Anfrage senden", um einen Zielspieler auszuwählen.
- Wähle "Anfragen verwalten", um offene Teleport-Anfragen anzusehen, zu akzeptieren oder abzulehnen.
